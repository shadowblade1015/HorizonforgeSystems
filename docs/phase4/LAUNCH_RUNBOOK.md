## 5. Rollback without losing progress

1. Stop further rollout/promotion. Preserve the failing source/output, release identity and redacted evidence. Ask affected players to keep the tab open and export current/original recovery data where possible, avoiding extra stale tabs. Do not ask them to clear site data.
2. Select a known compatible **Phase 3F-or-later protocol** candidate whose save schema/settlement handling remains compatible. Restore matching site/build/generator/worker tooling in a reviewed change and rebuild/test; do not independently downgrade just engine, HTML or worker.
3. Never deploy the pre-3F archived worker or blindly use an old Vercel rollback target: its skipWaiting/cleanup/unversioned policy can remove new caches and reintroduce mixed code. Deployment-history rollback must be checked for worker-protocol and save compatibility first.
4. Keep old immutable release URLs available when possible. New dist contains the new tree; older clients rely on their pinned cache if the host no longer serves their tree. Browser eviction can remove it. Missing old bytes must fail closed, not substitute current scripts. If unavailable, export progress, close older clients and safely reopen the ready compatible release.
5. Use explicit protected save/update approval. No automatic reload of all active clients, downgrade of localStorage or deletion of backups/recovery keys. A rollback is an application change, not a save rollback.
6. Re-run baseline, upgrade, pending/old client and recovery checks; inspect production response identities after authorized rollback. Record approval and outcome. Platform rollback/alias promotion operations require separate explicit authorization.

Local output recovery with no builder running may rename a preserved `.dist-backup-*` into dist after preserving current output. An interrupted rename can leave dist absent; inspect retained staging/backup and remove `.build.lock` only after proving no builder is active. Historical archive extraction is disposable forensic recovery, not a production worker rollback.
